# Production Audit Report Generation Command

Generate a comprehensive production readiness audit report from the findings collected in `.claude/production-audit/findings/`.

## Arguments

- `--domain <name>` - Generate report for specific domain only:
  - `code-architecture`
  - `testing-reliability`
  - `performance-scalability`
  - `operations-readiness`
  - `feature-practices`

## Execution Steps

### Step 1: Verify Audit Data

1. Check that `.claude/production-audit/` directory exists
2. If not exists, display error:
   ```
   No audit data found. Run /production-audit:audit first to collect findings.
   ```
3. Read `audit-state.md` to get audit metadata
4. Read `stack-profile.md` for technology context

### Step 2: Collect Findings

Read all finding files from `.claude/production-audit/findings/`:
- `code-architecture.md`
- `testing-reliability.md`
- `performance-scalability.md`
- `operations-readiness.md`
- `feature-practices.md`

If `--domain` specified, only read that domain's file.

Parse findings to extract:
- Finding ID
- Severity
- Domain
- Best Practice Reference
- Status
- Description
- Evidence
- Recommendation
- Source (for FP findings)

### Step 3: Generate Report

Create report in `.claude/production-audit/reports/` with timestamp:
- `production-audit-report-YYYY-MM-DD.md`

## Error Handling

- If no findings exist, generate report noting clean audit with congratulatory message
- If some domains have no findings, note "No findings — all checks passed" for that domain
- Handle malformed finding files gracefully
